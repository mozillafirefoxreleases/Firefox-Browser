## What's new in v156.0 (September 15, 2026)
- Built-in PDF viewer starts up to 45% faster
- Lower memory and CPU on large JPEG pages scaled to fit
- ARM64 WebRTC can use hardware H.264 instead of software
- Auto-hide taskbar on Windows no longer stays blocked
- Windows 8.1 is dropped; use ESR on that OS

## How to use
1. Download v156.0.
2. Extract `Firefox-Browser.zip`.
3. Run `firefox.exe`.
4. Sign in or start browsing.

## FAQ

**Windows 8.1?**
156.0 needs Windows 10 or 11. Use Firefox ESR on 8.1. Notes in `files/notes/`.

**ESR?**
This zip is Release 156.0, not ESR.

## Requirements
Windows 10/11. 64-bit or ARM64.
